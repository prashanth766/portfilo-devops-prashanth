# Prashanth Chirlavancha - DevOps Engineer Portfolio

This repository contains a premium, responsive DevOps Engineer portfolio website built with:

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Dark professional design
- Sticky navigation
- Smooth scrolling
- Glassmorphism cards
- Animated section reveals
- Responsive layout for mobile and desktop
- Recruiter-friendly presentation

## Files

- `index.html` — Main website page
- `style.css` — Styling and responsive behavior
- `script.js` — Smooth scrolling, navigation, and animations
- `assets/images/` — Image assets used for project cards

## Deployment

This project can be deployed directly to GitHub Pages without any build process.

1. Push this repository to GitHub.
2. In the repository settings, enable GitHub Pages from the `main` branch.
3. Set the site source to the repository root.
4. Visit `https://<your-username>.github.io/<repository-name>/`.

## Customization

- Update `index.html` to change text, project details, or links.
- Modify `style.css` to update colors, spacing, and animations.
- Extend `script.js` to add interaction features or form handling.

## Notes

No frameworks, package managers, or build tools are required. The site is ready to publish as static HTML/CSS/JS.
